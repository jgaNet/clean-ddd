# 10. The remainder goes to the first member of the split

Members found it unfair that whoever pays always takes the odd cent. The rule changes.

- **From now on,** when an expense is split equally (request 4) or by shares (request 7), the remainder goes whole to the share of the member listed first in the split, whoever paid. Everything else about the split holds: the shares add up to the amount, exactly, and the payer is still one of the members of the split.

  For instance, 1000 split equally between three members, the payer listed second, is now 334 for the first member, and 333 for the payer and for the third.
- **Earlier expenses are not computed again.** An expense recorded before this change keeps the shares it was given, and the balances they make. An expense edited from now on (request 6) is split again, by the new rule, as any edit splits it.
- **Splits by exact amounts** (request 7) have no remainder, and do not change.

The API works as request 1 says.
