# 2026-09-29 — "Tags on a note" (value object)

**Base:** `main` at `30f7b94`. **Agent:** Claude, fresh session, isolated worktree. **Result branch:** [`eval/note-tags`](https://github.com/jgaNet/clean-ddd/tree/eval/note-tags) (commit `f2b0e25`, 24 files, +498/−28; not merged).

## The request

> Users want tags on their notes. A note can have up to five tags. A tag is 2 to 20 characters, lowercase letters and digits only, and a note can't have the same tag twice. Tags are set when the note is created and can be changed later by the owner. They should show up when I read a note.

Chosen to exercise the value-object shape (`create()` → `Result`), its exceptions, the snapshot and reconstitution throwing on corrupted data (ADR 4), a change to an existing command, and the schema sentence added after the first evaluation.
