## What else the reader flagged

- **t3 (A pilot) can forge tokens.** With `TOKEN_SECRET` unset, the JWT secret falls back to a fixed string, and the role claim is trusted from the token. The agent took the pattern from the reference: `typescript/src/Bootstrap/Fastify/application.settings.ts` falls back to a fixed development secret as well. t2 and t4 fall back to random bytes per process.
- **t3 leaks which account ids exist.** Sharing checks whether the recipient exists before checking who owns the note.
- **t3 refuses a plan switch to the plan already held**, which the backlog does not name.
- **Login timing in t1 and t3**: an unknown email skips the hash. t2 and t4 compare against a decoy hash.
- **t1 rethrows an error that is not a domain error.** The request answers 500, and the operation stays `PENDING`.
- **t1's tokens never expire.**
- **t2's composition root offers no clock**, so its reminder tests sleep for 800–900 ms.
- **t2–t4 share an error handler that writes `error.message` unescaped into HTML** on the htmx path. That code comes from the created project.
