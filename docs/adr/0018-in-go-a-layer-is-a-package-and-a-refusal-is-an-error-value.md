# 18. In Go, a layer is a package, a refusal is an error value, and go/parser holds the table

## Context

ADR 11 made the reference a repository of several languages under one contract; ADR 12 (Rust) and ADR 15 (Python) each said what their language brings and where its idiom departs from the TypeScript one. Go is the fourth language, and it was written in one pass: the building blocks, the shared kernel, the four contexts, the bootstrap, the SQLite adapters, the tool, the binding, the documents, with the shared API scenario (ADR 16) as the finishing line.

Four questions came with the port, each a place where the TypeScript idiom does not transpose as is: the language has no inheritance and no exceptions; a `Result` type with `isFailure()` narrowing has no equivalent a Go reader would recognise; a package cannot hold a method generic over its receiver; and the compiler holds no boundary between the packages of one module, so nothing refuses a Domain package importing `net/http`.

## Decision

- **A tree is a directory of the module, a layer a package named after the contract's layer in lowercase.** `clean-ddd/architecture/domain`, `clean-ddd/sharedkernel/application`, `clean-ddd/contexts/notes/domain/note`, `clean-ddd/bootstrap`: what a file imports is the module path, so a boundary is visible in every import line. The wiring is one file beside the layer directories (`contexts/notes/module.go`, package `notes`). The sub-packages of a layer (`application/commands`, `application/queries`, `application/events`, `domain/note`) are the layer's; an importer aliases a package whose name collides (`kernel "clean-ddd/sharedkernel/application"`).
- **A refusal is an error value.** A behaviour returns `error`; a `*domain.Exception` (service, type, message, context) is what it carries, read with `domain.Refusal(err)`; a handler passes it on with `if err != nil { return zero, err }`. That is Go's own `Result`: the `(T, error)` pair, and the one thing the whole language already agrees on. A panic is reserved for corrupted state and programming errors; the base handlers recover one into a failed operation (DOMAIN-RESULT, ADR 1).
- **Composition where TypeScript inherits, generic functions where it has template methods.** An aggregate embeds `domain.AggregateRoot` (identity, version, `Record()`, `PullDomainEvents()`); a value object is a struct with one unexported field and a constructor returning `(T, error)` — the unexported field is what keeps the rule, the struct's `==` is the equality. A handler is a struct with `Execute()`; the template method is a generic function over a small interface: `application.Run(handler, command, ctx)` for a command (guard, log, transaction, safety net), `application.Query(handler, params, ctx)` for a query, and `application.Command(handler)` / `application.Reaction(handler)` build the subscription that puts the handler on the bus under its event's type name. A module finds a handler by its type (`application.QueryOf[*GetNoteHandler]`, applied to the module).
- **An event is a struct embedding the marker of its kind** (`domain.CommandEvent`, `domain.DomainEvent`, `domain.IntegrationEvent`), its exported fields the payload, its type name the channel, read by `domain.NameOf()` with reflection — the one place the mechanics use it, so that an author never writes a name twice. The public name strips the suffix (`domain.PublicNameOf`), as every language does (API-ONE-SURFACE).
- **The bus runs a dispatch in a goroutine**, and `Settle()` waits for what is in flight: what Python schedules as a task and Rust spawns on the runtime, Go does with `go` and a `sync.WaitGroup`. The execution context guards its after-commit callbacks with a mutex, since reactions of one request run concurrently.
- **A go/parser walk is the linter and the check.** `tools/conventions` reads every import of every file of the language's trees — never building them — classifies the file by its path and resolves each import path to a word of the contract's vocabulary (`own.Domain`, `architecture.Application`, `others.Domain`, `libraries`…), held to the file's row of the table. The standard library is neutral except the packages the binding names as libraries (`net/http`, `database/sql`, `encoding/json`): a Domain package importing a transport is refused like any adapter library. `can-import <file> <path>` answers before an import is written. A Go import path is always absolute: ARCH-RELATIVE has nothing to refuse here, and the binding says so.
- **The toolchain is the standard one**: `go` modules, `gofmt`, `go vet`, `golangci-lint` with its default linters, `go test` with tests beside what they test (`_test.go`, internal), `net/http` and its 1.22 mux patterns for the transport (no framework), `database/sql` on `modernc.org/sqlite` (no cgo), `golang-jwt`, `x/crypto/bcrypt`, `coder/websocket`.

## Consequences

- The boundary is as strong as the tool: a package imported through a build tag the walk does not see, or code generated at build time, is invisible to it. This reference does neither, and the guide says not to.
- A violation is found by `go run ./tools/conventions`, not by the compiler; the five checks are the gate, as in the other languages. `can-import` is the editor-time answer.
- A refusal is as visible as any Go error, and as easy to drop: `_ = note.Archive(actor)` compiles. `golangci-lint`'s `errcheck` is what refuses that, which is why the lint is one of the five checks and not an option.
- Every handler's `Execute` names its result type, so the operation's result is typed at the handler and `any` only on the bus; `application.Nothing` says, in the signature, that a command answers nothing, and the record carries no result for it.
- Aliasing a package at the import (`kernel`, `archinfra`, `notesinfra`) is the price of naming every layer directory after the contract; the alternative, a unique package name per layer per context, would have put the context's name in every package and hidden the layer.

## When to revisit

If a second Go tool reads the table (an editor plugin, a pre-commit hook), it should import `tools/conventions` as a package rather than reread the YAML. If the language gains a way to declare a package's allowed imports, the tool should compare that declaration to the contract, as `cargo run -p conventions` compares the crate graph.
